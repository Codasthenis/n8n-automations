### ۲. فایل `README.md` اختصاصی برای پروژه‌ی سندر

این رو داخل پوشه‌ی پروژه‌ی سندر (`/n8n-automations/pachef/README.md`) قرار بده:

```markdown
# 🚀 پروژه سندر (Pachef - ابزار مانیتورینگ هوشمند فریلنسری)

یک اتوماسیون پیشرفته در **n8n** که به صورت هوشمند و خودکار، پلتفرم‌های فریلنسری (مثل Karlancer) را برای پروژه‌های جدید رصد کرده، اطلاعات را فیلتر و پردازش می‌کند و در نهایت نتایج را از طریق ربات تلگرام گزارش می‌دهد.

---

## ⚙️ معماری و نحوه عملکرد (Workflow Logic)

این پروژه از چند بخش کلیدی تشکیل شده است:
1. **HTTP Request Node**: دریافت مهارت‌ها و داده‌های اولیه از طریق API یا وب‌سایت هدف.
2. **Dynamic URL & Parsing**: ساخت پویای آدرس‌ها برای جستجوی دقیق پروژه‌ها.
3. **JavaScript Code Node**: پردازش و تجمیع داده‌ها با استفاده از متدهای مدرن جاوا اسکریپت (`flatMap`, `filter`, `map`) برای استخراج ۳ پروژه‌ی پرطرفدار و جذاب.
4. **Telegram Integration**: فرمت کردن متن و ارسال خروجی تمیز و خوانا به کاربر.

---

## 📂 فایل‌های پروژه
- `pachef.json`: آخرین و پایدارترین نسخه‌ی این اتوماسیون (بهینه‌سازی شده برای مدیریت صحیح آرایه‌ها و جلوگیری از خطاهای ایندکسینگ).

---

## 📥 نحوه ایمپورت و استفاده

1. وارد پنل ابری n8n خود شوید.
2. از بخش منو، گزینه‌ی **Import from File** را انتخاب کنید.
3. فایل `pachef.json` را آپلود کنید.
4. متغیرها و توکن ربات تلگرام خود را در نود مربوطه تنظیم و اتوماسیون را فعال (`Active`) کنید.
