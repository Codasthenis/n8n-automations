# 🤖 n8n Automation Toolbox

مجموعه‌ای از اتوماسیون‌ها و جادوی n8n برای بهینه‌سازی کارهای روزمره، مانیتورینگ پروژه‌ها و ارتباط با ابزارهای مختلف (مثل تلگرام، پلتفرم‌های فریلنسری و...).

## 📂 ساختار ریپازیتوری

هر پروژه در پوشه‌ی مجزای خود قرار دارد و شامل فایل‌های خروجی n8n (`.json`) و مستندات مربوطه است:
```text
.
├── Pachef/          # پچف (مطلع‌ساز هوشمند پروژه‌های فریلنسری)
│   ├── pachef.json   # آخرین نسخه پایدار و بهینه‌سازی شده
│   └── README.md            # مستندات و راهنمای پروژه سندر
└── README.md                # مستندات کلی ریپازیتوری
